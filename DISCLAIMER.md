## 1. What this project is

nfs13 is an independent, unofficial, non-commercial software project made by
the sn0wd0wn team for game preservation and interoperability. It lets owners of
Need for Speed: Most Wanted (2012) run their own private server so their own
copies of the game can play together.

The project consists only of our own original work: server code, scripts,
documentation, and logs and screenshots from our own sessions.
